# 💗 Nandu Birthday Surprise

A small interactive birthday website made with plain HTML, CSS and JavaScript.

## Folder structure

```text
nandu_birthday_website/
├── index.html
├── style.css
├── script.js
└── assets/
    ├── photos/
    │   ├── photo1.jpeg
    │   ├── photo2.jpeg
    │   ├── photo3.jpeg
    │   └── photo4.jpeg
    └── songs/
        ├── song1.mp3
        ├── song2.mp3
        ├── song3.mp3
        └── song4.mp3
```

## Add your 4 songs

Put your four audio files inside:

`assets/songs/`

Rename them exactly:

- `song1.mp3`
- `song2.mp3`
- `song3.mp3`
- `song4.mp3`

You can change the names shown on the four song cards inside `script.js`.

## Run

Just double-click `index.html`.

For the best result, use VS Code + Live Server.

## Flow

1. Enter the correct name: NANDITA
2. Solve the letter puzzle
3. Choose one of 4 songs
4. "Aaj toh kuch special hai..." prompt
5. Enter 5 October
6. Birthday screen opens with photos, selected song and message
